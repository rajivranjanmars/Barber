# Barber — Royal Cuts Barber Studio

React and Vite project scaffold for a barber-studio website. The HTML entry describes Royal Cuts grooming services and the dependency set includes routing, animation, and icons.

## Getting started

Install with `npm ci`. The configured commands are `npm run dev`, `npm run build`, and `npm run lint`.

**Repository status:** `index.html` references `src/main.jsx`, but the application source directory is missing from this checkout. Restore the application source before expecting the development server or production build to render the site.
